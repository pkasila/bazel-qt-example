# Лабораторная работа №1: Прокрастинация
## Функционал
Приложение помогает повторять билеты перед экзаменом. Вы можете задать общее количество билетов, редактировать их названия и менять статус: серый (не трогали), жёлтый (надо повторить ещё), зелёный (выучил). Билеты выбираются случайно — но только из тех, что ещё не выучены. Есть навигация «вперёд/назад» и два прогресс-бара: общий прогресс и количество выученных билетов. Интерфейс адаптивный — при изменении размера окна всё остаётся на своих местах.
## Как запустить
```bazel run //:task1```
