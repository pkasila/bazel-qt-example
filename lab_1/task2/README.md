# I-Tetris (Line Tetris)
## Задумка
Упрощённая версия Тетриса: используется только одна фигура — палка 1×4. Можно вращать, перемещать и собирать линии. При сборе линии из 10 блоков она сгорает, начисляются очки.
## Правила игры
1. Сверху появляется палка 1×4
2. Перемещайте её стрелками ← и →
3. Вращайте стрелкой ↑
4. Собирайте **горизонтальные линии из 10 блоков** (полная ширина поля)
5. За каждую собранную линию: +100 очков
6. Если палка не может появиться на поле — игра окончена
# Запуск
```bazel run //:itetris```
