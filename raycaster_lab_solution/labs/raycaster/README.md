# Raycaster lab solution

Архив содержит папку `labs/raycaster`, которую можно положить в репозиторий `pkasila/bazel-qt-example`.

## Что реализовано

- `Ray`, `Polygon`, `Controller` по интерфейсу из задания.
- Вычисление пересечения луча с рёбрами многоугольников **без** `QPolygon`, `QLineF` и других Qt helper-классов геометрии.
- Режим `light`: кластер источников света перемещается мышью.
- Режим `polygons`:
  - ЛКМ — начать / добавить вершину,
  - ПКМ — завершить текущий многоугольник.
- Построение освещённой области через:
  - каст лучей на вершины,
  - поворот лучей на `±0.0001`,
  - поиск ближайших пересечений,
  - удаление почти совпадающих соседних лучей,
  - сортировку по углу.
- Полутени: используется несколько близко расположенных источников света с полупрозрачной заливкой.

## Замечания по интеграции

В архиве я сделал цель `basics` и добавил alias `raycaster`, чтобы было удобнее вызывать и по формулировке задания, и по привычному shorthand Bazel.

Ожидаемый запуск после копирования в репозиторий:

```bash
bazel run //labs/raycaster
```

Если в вашем шаблоне репозитория имена внешних Qt-таргетов отличаются от `@qt//:QtCore`, `@qt//:QtGui`, `@qt//:QtWidgets`, поправьте только `deps` в `labs/raycaster/BUILD` — остальные файлы к этому не привязаны.
