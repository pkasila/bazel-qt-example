# 🌍 Polyglot Mastery (Lab 3)

Polyglot Mastery — это кроссплатформенное десктопное приложение для изучения языка, написанное на **C++ (Qt 6)** с использованием системы сборки **Bazel**. Проект реализует все требования Лабораторной работы №3, вдохновляясь механиками Duolingo.

## 🚀 Особенности (Features)
-  **Модульная архитектура**: Строгое разделение UI, Контроллера и Репозитория.
-  **Адаптивный UI**: Использование `QVBoxLayout` и `QHBoxLayout` для идеального масштабирования. 
-  **QStackedWidget**: Бесшовное переключение между Главным меню, Игрой и Настройками без создания новых окон.
-  **Система Меню (MenuBar)**: Нативное меню для выбора уровня сложности (через `QInputDialog`) и перехода в настройки.
-  **Различные типы заданий**:
   - **Translation Practice**: Перевод с клавиатуры в `QLineEdit`. Умный алгоритм сравнения (учитывает несколько вариантов, игнорирует регистр).
   - **Grammar Practice**: Выбор правильного ответа из нескольких вариантов через `QRadioButton`.
-  **Оценка и Таймер**: Система стриков, ограничение по времени и количеству "Жизней".
-  **Динамический интерфейс**: Смена светлой и темной тем оформления, анимации и звуковые эффекты (через `QSoundEffect`).

## 🛠️ Сборка и запуск (Build & Run)

Проект использует **Bazel** с поддержкой `rules_qt`. Собирается и работает как на **macOS**, так и на **Linux**.

### Запуск одной командой
```bash
bazel run //labs/duolingo:duolingo
```

## 🎮 Управление и горячие клавиши

- **`Enter` / `Return`** — подтвердить (Check Answer).
- **`H` / `Р`** — вызвать подсказку (Hint) для текущего вопроса.
- **`Escape`** — снять фокус с текстового поля (удобно для вызова горячей клавиши `H`).
- **Меню -> Select Difficulty Dialog** — диалоговое окно формального выбора сложности.

---

**Бонусные системы (Advanced):**
- Музыкальное сопровождение (фоновая музыка меняется при потере жизней).
- Анимация "тряски окна" при неправильном ответе.
- Кастомный режим (Custom Mode), где можно задать время, жизни и количество вопросов через QSlider.
