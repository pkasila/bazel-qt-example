# Аналог приложения Duolingo 

## Функционал приложения:

- Регистрация пользователя с запоминанием его данных -- имя пользователя, email (не обязательно)
- Вход пользователя по имени и паролю
- Для безопасности пользователей пароль шифруется при помощи sha256, к паролю припысавается "соль" для избежания взлома по радужной таблице
- Стилистика приложения в зелёных тонах, наподобие реального приложения duolingo, полностью прописана в qss файле 
- При запуске приложения можно выбрать один из 15 уроков, которые соответсвуют различным тематикам
- Во всех уровнях есть три режима обучения: `Translation`, `Grammar`, `Audio`.

   P. S. Не удивляйтесь, в режиме `Audio` уровня профессии стоит слово mother, потому что быть мамой -- самая тяжёлая и важная работа. (Забыл сгенерить аудиофайл).
- В каждом упражнении стоит таймер на две минуты
- В каждом упранении рахрешается допустить не более трёх ошибок
- В режимах `Grammar` и `Audio` при неправильном ответе высвечивается исправление
- Звезда за режим ставится только за полностью правильное выполнение
- При различных запусках вопросы перемешиваются
- Ответы регистроустойчивы, но аналоги английских букв на других раскладках клавиатуры (например, русская и английская буквы "O") считаются различными
- У каждого пользователя ведётся статистика с временем провождения в игре, дата регистрации, количество выполненных упражнений, количество звёзд
- Чтобы изменить уровни надо поменять значения в `createlesson` в реализации класса `DataManager`
- Чтобы добавить новое упражнение надо:
- - Импортировать в папку `audio` новый звук
- - Изменить `resources.qrc`
- - Изменить `BAZEL.build`
- - Добавить в `datamanger.cpp` в методе `PopulateInitialData` новый `createLesson`
- - Очистить старую БД
- - Выполнить ``bazel clean --expunge`` в терминале из директории проекта
- - Выполнить ``bazel run duolingo`` из директории проекта
