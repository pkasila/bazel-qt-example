# Language Learning App — Лабораторная работа №3

Данное приложение представляет собой интерактивный тренажер для изучения иностранного языка, разработанный на C++ с использованием фреймворка **Qt 6**. Проект собран с помощью системы сборки **Bazel**.

## 🚀 Основной функционал

В соответствии с требованиями лабораторной работы, в приложении реализованы:

1.  **Layout Management**: Интерфейс построен на адаптивных компоновщиках (`QHBoxLayout`, `QVBoxLayout`), обеспечивающих корректное масштабирование окна.
2.  **Dynamic Widgets**: Использование `QStackedWidget` для динамической смены экранов (приветствие / режим упражнений).
3.  **Типы заданий**:
    *   **Translation**: Ввод перевода текста вручную через `QLineEdit`.
    *   **Grammar**: Выбор правильного грамматического варианта через `QRadioButton`.
4.  **Система оценки**:
    *   Начисление баллов (10 баллов за полностью выполненный блок).
    *   Контроль ошибок (максимум 3 ошибки, после чего упражнение прерывается).
5.  **Таймер и прогресс**:
    *   Ограничение времени на выполнение (60 секунд).
    *   Визуализация прогресса выполнения заданий через `QProgressBar`.
6.  **Система помощи**: Вызов контекстной подсказки по нажатию клавиши **'H'** (Help).
7.  **Меню**: Реализован `QMenuBar` с возможностью настройки (диалоговое окно сложности).

## 🛠 Стек технологий

*   **Язык**: C++17
*   **Фреймворк**: Qt 6.x (Widgets)
*   **Система сборки**: Bazel (Bzlmod)
*   **Среда**: WSL (Ubuntu) / Linux

## 📦 Сборка и запуск

### Предварительные требования (для WSL/Ubuntu)
Убедитесь, что у вас установлены необходимые библиотеки для работы Qt:
```bash
sudo apt update
sudo apt install build-essential libgl1-mesa-dev libxkbcommon-x11-0 libfontconfig1 fonts-liberation
```

### Команды сборки
Для компиляции проекта используйте:
```bash
bazel build //labs/lab3:basics
```

### Команда запуска
Для запуска приложения:
```bash
bazel run //labs/lab3:basics
```

## ⌨️ Горячие клавиши
*   `H` — Показать подсказку к текущему заданию.
*   `Enter` (в поле ввода) — Отправить ответ.
