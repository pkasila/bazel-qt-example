# Лабораторная работа 1.3: Waifu Mood Manager

## Творческая задумка

"Waifu Mood Manager" - это интерактивный симулятор аниме-персонажа, который реагирует на действия пользователя. В центре окна находится виртуальная "тянка", настроение которой зависит от взаимодействия с пользователем. Приложение демонстрирует сложную обработку событий мыши и клавиатуры, а также различные виджеты Qt для создания интерактивного интерфейса.

## Используемые виджеты

### Базовые виджеты (4):
1. **QPushButton** - Кнопка "Гладить" для повышения счастья персонажа
2. **QProgressBar** - Шкала счастья (0-100%), которая медленно падает со временем
3. **QLCDNumber** - Счетчик кликов по кнопке "Гладить"
4. **QCheckBox** - Переключатель "Ecchi Mode", меняющий цветовую схему интерфейса

### Сложные виджеты (2):
1. **QSlider** - Регулятор скорости падения шкалы счастья с красивой стилизацией
2. **QScrollArea** - Гардероб с кнопками для смены нарядов персонажа

## Взаимодействие с приложением

### Основные действия:
- **Кнопка "Гладить"**: Увеличивает счастье на +10 и счетчик кликов на +1
- **Клик на голову персонажа**: В обычном режиме увеличивает счастье на +5, в Ecchi режиме вызывает смущение на 2 секунды
- **Клик по персонажу в Ecchi режиме**: Вся область персонажа становится кликабельной и вызывает смущение
- **Клавиша 'S'**: Мгновенно заполняет шкалу счастья до 100%
- **Ecchi Mode**: Переключает цветовую схему между милой и "взрослой"
- **QSlider**: Регулирует скорость падения счастья (1 = медленно, 10 = быстро)
- **Гардероб**: Выбор одного из 8 нарядов для персонажа

### Состояния персонажа:
- **😊 Счастливая** (счастье ≥ 80%): Персонаж радостна и довольна
- **😊 Нормальная** (счастье 40-79%): Обычное состояние
- **😢 Грустная** (счастье < 40%): Персонаж грустит и нуждается во внимании
- **😳 Смущенная** (клик по персонажу в Ecchi режиме): Временное состояние смущения

### Доступные наряды:
1. School Uniform (школьная форма)
(на 2-8 токенов генерации изображений не хватило, поэтому лаба будет обновляться)
2. Casual (повседневная одежда)
3. Maid (горничная)
4. Yukata (юката)
5. Idol (идол)
6. Nurse (медсестра)
7. Teacher (учительница)
8. Cat Girl (кошечка)

## Технические особенности

### Обработка событий:
- **mousePressEvent**: Переопределен для определения кликов на область головы персонажа
- **keyPressEvent**: Обрабатывает нажатие клавиши 'S' для мгновенного повышения счастья
- **Таймеры**: Два таймера - для падения счастья и сброса смущения

### Лейауты:
- **QHBoxLayout**: Основное разделение окна на левую и правую части
- **QVBoxLayout**: Вертикальное расположение элементов в каждой части
- **QScrollArea**: Прокручиваемая область для гардероба

### Стили:
- **QSS стили**: Динамическое изменение цветовой схемы в зависимости от режима
- **Адаптивный дизайн**: Все элементы корректно масштабируются при изменении размера окна

## Как использовать

1. **Запустите приложение**: Вы увидите персонажа в левой части окна
2. **Гладите персонажа**: Нажимайте кнопку "Гладить" для повышения счастья
3. **Следите за настроением**: Шкала счастья показывает текущее состояние
4. **Кликайте на голову**: В обычном режиме - погладить (+5 счастья), в Ecchi режиме - вся область персонажа вызывает смущение
5. **Используйте клавиатуру**: Нажмите 'S' для мгновенного счастья
6. **Меняйте наряды**: Выбирайте разные костюмы в гардеробе
7. **Настраивайте скорость**: Используйте красивый QSlider для контроля падения счастья
8. **Переключайте режимы**: Включите Ecchi Mode для изменения интерфейса и расширенного взаимодействия

## Креативность и дизайн

Приложение сочетает в себе:
- **Милую эстетику** аниме-стилистики с эмодзи для представления эмоций
- **Интерактивность** через различные способы взаимодействия (мышь, клавиатура, виджеты)
- **Динамичность** - персонаж реагирует на действия пользователя в реальном времени
- **Персонализацию** через гардероб и режимы интерфейса
