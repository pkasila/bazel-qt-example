Великая мысль данного приложения научиться кодить как в рпг через огромное количество гринда, но чтобы было приятнее есть переходы на новые уровни и все такое(короче, пытаемся не прокрастинировать).
Что у нас есть:
1. Basic Widgets:
QLineEdit (Имя героя):
Взаимодействие: Сигнал textChanged.
Эффект: При вводе текста мгновенно обновляется заголовок персонажа.
QSpinBox (Часы практики):
Взаимодействие: Сигнал valueChanged.
Эффект: Каждое изменение значения добавляет опыт (XP) в общак. Лимит 999,999.
QCheckBox (Hardcore Mode):
Взаимодействие: Сигнал toggled.
Эффект: Меняет визуальный стиль ранга на красный и добавляет суффикс [HARDCORE].
QPushButton (Кнопка ГРИНД):
Взаимодействие: Сигнал clicked.
Эффект: Ручное добавление +10 XP.
2. Other Widgets:
QLCDNumber (Уровень): Отображает текущий уровень героя. Обновляется при накоплении 100 XP.
QListWidget (Дерево навыков):
Взаимодействие: Сигнал itemDoubleClicked.
Эффект: При двойном клике навык помечается как изученный, начисляется бонусный опыт. Дважды начисления нет.
QProgressBar (Шкала опыта): Визуализирует текущий прогресс внутри уровня.
Space (Пробел): Основная клавиша для гринда. Работает как горячая клавиша для кнопки получения опыта. Важно: пробел не срабатывает для гринда, если фокус находится в поле ввода имени (чтобы можно было вводить пробелы в никнейме).
Escape: Мгновенно очищает поле имени и сбрасывает фокус на главное окно.
Клавиша R (английская): Секретная клавиша для получения случайного бонусного опыта.
Динамический Rank: При достижении определенных уровней автоматически меняется текстовый ранг (Intern -> Junior -> Middle и т.д.).
Layouts: Использован QHBoxLayout как основной контейнер. Внутри него два QVBoxLayout.
Resize: Установлены коэффициенты растяжения (stretch) 1:2. Левая панель управления компактная, правая панель с деревом навыков и уровнем занимает основную часть экрана. Окно корректно масштабируется, минимальный размер ограничен (setMinimumSize).
Design: Применена темная тема через Qt Style Sheets (QSS), ибо светлая кринж.
