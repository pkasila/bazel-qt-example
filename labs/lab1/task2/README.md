# Лабораторная работа №1 (Задание 2): Однорукий бандит

## Описание задумки
В качестве творческого задания ("Свободное плавание") я реализовал игру "Однорукий бандит" (слот-машина). Игроку выделяется стартовый баланс (1000 монет). Внизу интерфейса можно настроить размер ставки (любая сумма вплоть до текущего баланса) и включить режим авто-игры. Барабаны (3 LCD-номера) крутятся с анимацией. Математика выигрыша:
- **Все 3 цифры разные** — Проигрыш (выигрыш 0).
- **Любые 2 цифры совпали** — Успех (ставка * 2).
- **Все 3 цифры совпали** — Джекпот (ставка * 10).
- **Выпало [7] [7] [7]** — Мега-Джекпот (ставка * 50).

Интерфейс выполнен в единой адаптивной темной теме, с ровной сеткой (`QGridLayout`, `QVBoxLayout`, `QHBoxLayout`), и корректно масштабируется при изменении размеров окна. Включена дополнительная кнопка «Начать заново», которая позволяет перезапустить игру в случае полного банкротства.

## Взаимодействие (Сигналы и Слоты)
Проект строго удовлетворяет условию: использованы 4 обязательных виджета и 2 дополнительных (не из списка Basic). Все они тесно связаны сигналами и слотами.

1. **`QPushButton`** (кнопка "Дернуть рычаг!" и кнопка "Начать заново")
   - *Сигнал:* `clicked`
   - *Действие:* Основная кнопка снимает монеты с баланса, моментально блокирует элементы управления (чтобы нельзя было сжульничать и изменить ставку), запускает таймер барабанов в `SlotMachineWidget`. Кнопка старта заново восстанавливает баланс до 1000.

2. **`QSpinBox`** (выбор размера ставки)
   - *Сигнал:* `valueChanged`
   - *Действие:* Инициирует проверку платежеспособности. Лимит ставки автоматически подстраивается под любой размер текущего баланса пользователя. Если выбранная ставка превышает остаток, кнопка запуска деактивируется.

3. **`QLabel`** (информационное табло)
   - *Действие:* Служит главным индикатором состояния игры. Реагирует на остановку барабанов: пишет "Крутим..." в процессе, а затем выдает результат. Цвет и стиль текста меняются через `QSS`: красным для проигрыша, золотым или зеленым на победу. В случае провала до 0 баланса блокирует окно надписью "Вы банкрот!".

4. **`QCheckBox`** (режим "Авто-игра")
   - *Сигнал:* `toggled`
   - *Действие:* При включении позволяет не нажимать кнопку руками. После каждого спина запускается скрытый таймер на 1 секунду. При его истечении — игра запускается снова, если баланса хватает для ставки.

5. **`QLCDNumber`** (три барабана слот-машины — *не базовый виджет*)
   - *Действие:* Реагируют на тики `QTimer`. Каждые 50 мс числа обновляются через `QRandomGenerator`, имитируя крутящиеся диски.

6. **`QProgressBar`** (шкала баланса — *не базовый виджет*)
   - *Действие:* Наглядно показывает текущий баланс игрока. Динамически адаптирует свои размеры, если выигрыш очень крупный (например Мега-Джекпот). Формат текста: `%v монет`. Обновляется каждый раз после расчетов игры.

## Архитектура и запуск
Я разделил логику на два уровня абстракции:
1. `SlotMachineWidget` — инкапсулирует барабаны, таймер и их анимацию. Ничего не знает о ставках. Когда останавливается, кидает кастомный сигнал `SpinningStopped`.
2. `MainWindow` — управляет игровой сессией, балансом и связывает все элементы воедино.

Для сборки используется **Bazel** (`bazel run //labs/lab1_task2:app`).
