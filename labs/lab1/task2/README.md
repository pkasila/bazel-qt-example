# Лабораторная работа №1, Задание 2: random_tasker

## Идея
Календарь с задачами, который может распределить список задач на случайные дни в диапазоне

## Выполненные требования
**4 Basic Виджета:**
1. `QListWidget`
2. `QPushButton`
3. `QLineEdit`
4. `QLabel`

**2 "Других" виджета:**
1. `QCalendarWidget`
2. `QDateEdit`


## Функции
1.  **Простое добавление**
2.  **Случайное добавление:** Распределяет задачи в промежутке, подсвечивает куда добавились задачи.
3.  **Отмена случайного добавления** Выдает случайный невыученный билет.
4.  **Счетчик задач на день:** Показывает количество оставшихся на день задач и общее количество задач.
5.  **Сохранение сессии:** Сохраняет изменения при простом закрытии окна.
6.  **Простое удаление** Удаляет выбранную задачу.
7.  **Пометка задач** Вычеркивает задачу из списка дел (типа она выполнена).
8.  **Полная очистка**
