# Лабораторная работа №1: Основы Qt

Данный проект состоит из двух основных заданий, объединенных общим графическим интерфейсом выбора (Launcher). Приложение разработано с использованием фреймворка **Qt 6** и системы сборки **Bazel**.

## Структура проекта

*   **Launcher**: Стартовое окно для выбора между Заданием 1 и Заданием 2.
*   **Задание 1 "Прокрастинация"**: Приложение для повторения экзаменационных билетов.
*   **Задание 2 "Space Control"**: Интерактивная панель управления космическим кораблем.

---

## Описание реализации

### Стартовое окно (Launcher)
При запуске открывается компактное меню. Оно управляет жизненным циклом окон:
*   При выборе задания текущее окно выбора закрывается (`this->close()`).
*   Выбранное задание инициализируется динамически.
*   Используется флаг `Qt::WA_DeleteOnClose` для автоматического освобождения памяти после закрытия окон заданий.

### Задание 1: Прокрастинация
Инструмент для эффективного повторения билетов перед экзаменом.

**Функционал:**
*   **Настройка:** `QSpinBox` позволяет задать количество билетов. При изменении числа прогресс сбрасывается, а список очищается.
*   **Визуализация:** `QListWidget` отображает билеты. 
    *   *Серый*: еще не открывали.
    *   *Желтый*: нужно повторить.
    *   *Зеленый*: выучено.
*   **Интерактивность:** 
    *   Двойной клик по билету переключает его статус (Зеленый <-> Желтый).
    *   Одиночный клик открывает панель редактирования.
*   **Редактирование:** Можно изменить название билета через `QLineEdit` (сохранение по нажатию Enter). Статус меняется через `QComboBox`.
*   **Умный рандом:** Кнопка "Следующий" выбирает случайный билет только из категории "не выученных" (серые и желтые).
*   **История:** Реализована кнопка "Предыдущий" через структуру данных `QStack`, позволяющая возвращаться к ранее просмотренным билетам.
*   **Прогресс:** Два `QProgressBar` наглядно показывают общий процент затронутых билетов и процент полностью готовых.

### Задание 2: Свободное плавание (Space Control)
Креативное приложение "Панель управления кораблем", демонстрирующее взаимодействие различных виджетов.

**Используемые виджеты:**
1.  **QSlider (Basic)**: Управление тягой двигателя.
2.  **QCheckBox (Basic)**: Активация силового щита.
3.  **QRadioButton (Basic)**: Переключение между "Тихим ходом" и "Боевым режимом".
4.  **QPushButton (Basic)**: Кнопка "Гиперпрыжок".
5.  **QLCDNumber (Other)**: Цифровое табло скорости.
6.  **QDial (Other)**: Выбор навигационного курса.

**Логика сигналов:**
*   Слайдер тяги напрямую связан с LCD-панелью.
*   Кнопка "Гиперпрыжок" заблокирована, пока не включены щиты (`QCheckBox`).
*   Вращение `QDial` динамически меняет заголовок окна, отображая текущий курс в градусах.
*   При совершении прыжка выводится диалоговое окно `QMessageBox`.

## Технические особенности
*   **Layouts**: Для обеспечения корректного ресайза и адаптивности интерфейса во всех окнах использованы `QVBoxLayout` и `QHBoxLayout`.
*   **Signals & Slots**: 
    *   Использованы как классические связки `connect`, так и современные лямбда-выражения для краткости кода.
    *   Обработаны события изменения текста, нажатия клавиш (Enter), кликов и изменения состояний.
*   **Bazel Integration**: В файле `BUILD` используется `qt_cc_library`, которая автоматически запускает `moc` для всех файлов, содержащих макрос `Q_OBJECT`.
