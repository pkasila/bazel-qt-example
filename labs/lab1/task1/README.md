# Лабораторная работа №1, Задание 1: exam_preparation_tool

## Идея
Приложение выдает билеты в случайном порядке для заучивания.

## Функции
1.  **Настройка количества билетов** Устанавливает количество билетов по выбору пользователя.
2.  **Настройка билетов:** Позволяет менять количество билетов
3.  **Следующий билет:** Выдает случайный невыученный билет.
4.  **Предыдущий билет:** Выдает предыдущий билет.
5.  **Сохранение сессии:** Сохраняет изменения при простом закрытии окна.
6.  **Пометки билетов:** Можно установить 3 типа билетов: не учил, надо повторить, выучил.
