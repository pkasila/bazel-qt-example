# Unit Converter — Конвертер Величин

## 📋 Описание приложения

Unit Converter — это приложение для конвертации единиц измерения между различными системами. 
Поддерживает три категории: Длина, Вес и Температура.

---

## 🧩 Использованные Виджеты

### 4 Basic Widgets (Базовые виджеты)

| № | Виджет | Переменная | Назначение | Сигнал | Слот (реакция) |
|---|--------|------------|------------|--------|----------------|
| 1 | `QComboBox` | `comboCategory` | Выбор категории конвертации (Длина/Вес/Температура) | `currentIndexChanged(int)` | `onCategoryChanged(int)` — обновляет списки единиц |
| 2 | `QComboBox` | `comboFrom` | Выбор исходной единицы измерения | `currentIndexChanged(int)` | `onLiveConvert()` — автоматический пересчёт |
| 3 | `QComboBox` | `comboTo` | Выбор целевой единицы измерения | `currentIndexChanged(int)` | `onLiveConvert()` — автоматический пересчёт |
| 4 | `QDoubleSpinBox` | `spinInput` | Ввод числового значения для конвертации | `valueChanged(double)` | `onLiveConvert()` — автоматический пересчёт |
| 5 | `QPushButton` | `btnConvert` | Кнопка запуска конвертации | `clicked()` | `onConvert()` — выполнение расчёта и вывод результата |

## ⌨️ Обработка Событий (Events)

### Переопределённое событие: `keyPressEvent(QKeyEvent *event)`

| Клавиша | Действие | Вызываемый метод |
|---------|----------|------------------|
| `Enter` / `Return` | Выполнить конвертацию | `onConvert()` |
| `Escape` | Очистить результат | `onClear()` |
| `↑` (Стрелка вверх) | Переключить категорию вверх | `comboCategory->setCurrentIndex(idx - 1)` |
| `↓` (Стрелка вниз) | Переключить категорию вниз | `comboCategory->setCurrentIndex(idx + 1)` |

## 🚀 Как Взаимодействовать с Приложением

### Пошаговая инструкция

1. **Выберите категорию** в выпадающем списке (Длина/Вес/Температура)
2. **Выберите исходную единицу** в поле "Из"
3. **Выберите целевую единицу** в поле "В"
4. **Введите значение** в поле "Значение" (или используйте стрелки спинбокса)
5. **Результат появится автоматически** (live-конвертация) или нажмите "Конвертировать"
6. **Смените тему** в выпадающем списке "Тема" для изменения внешнего вида
7. **Нажмите "Очистить"** для сброса поля ввода

### Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `Enter` | Конвертировать |
| `Esc` | Очистить |
| `↑` | Предыдущая категория |
| `↓` | Следующая категория |
