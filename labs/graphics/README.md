Описание режимов:
1. <Light> (Режим света): В этом режиме разрешено только перемещать основной источник света и его спутников по отведённой области, для его перемещения надо зажать любую клавишу мыши и перемещать курсор по экрану. Также для этого режима есть [x] CheckBox "Непроходимые фигуры", при активации которого источники света не могут пройти через границы многоугольника, а также не могут оказаться внутри нажатием на ЛКМ.
2. <Polygons> (Режим многоугольников): В этом режиме разрешается создавать многоугольники, при этом все источники света убираются. Самопересечения сторон многоугольников и пересечения сторон различных многоугольников запрещены (вершина не поставится в месте нажатия). Также до завершения создания многоугольника (нажатие ПКМ) есть возможность изменить последнюю поставленную вершину нажав на неё и перетащив куда-либо.
3. <Static-lights> (Статичные источники): Позволяет расставлять статические источники света в любом месте экрана отрисовки. Отображаемые источники светят жёлтым светом в ограниченном радиусе. Расставляются они нажатием на ЛКМ, удалить любой из них можно нажав рядом с ним правой клавишей мыши.

При изменении размера окна все вершины многоугольников находящиеся за пределом экрана удаляются, а если основной источник света при уменьшении экрана находится вне зоны видимости, то его свет пропадает.
Перемещение вершины во время создания многоугольников может создавать пересечения и самопересечения многоугольников, я решил оставить это как фичу для поломки отрисовки)

Запуск программы из папки (graphics): $ bazel run raycaster
