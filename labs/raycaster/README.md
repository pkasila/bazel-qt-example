# 2D Raycaster

Симуляция динамического освещения и теней на плоскости.

## Основные возможности
- Динамическое освещение с обсчетом препятствий в реальном времени.
- 4 режима работы: Обычный свет, Редактор полигонов, Мягкие тени и Статичные источники.
- Обработка коллизий: источники света автоматически смещаются при столкновении с объектами.
- Поддержка изменения размера окна и горячих клавиш.

## Управление по режимам

### 1. Light (Освещение)
- **Мышь**: Перемещение основного источника света.
- **Стрелки (← ↑ → ↓)**: Точное перемещение источника света.
- **Клавиша `C`**: Полная очистка всех полигонов.

### 2. Polygons (Редактор препятствий)
- **ЛКМ**: Добавить вершину (минимум 3 для создания полигона).
- **ПКМ**: Завершить текущий многоугольник.
- **Движение мыши**: Предпросмотр следующего ребра.

### 3. Soft Shadows (Мягкие тени)
- **Мышь/Стрелки**: Управление центром группы источников.
- **Особенности**: Плавное затухание теней за счет наложения 16 источников света.

### 4. Static Lights (Статичные источники)
- **ЛКМ**: Установить новый статичный источник света.
- **ПКМ**: Удалить последний установленный статичный источник.

## Сборка и запуск


### Сборка проекта:
```bash
bazel build //labs/raycaster:raycaster
```

### Запуск приложения:
```bash
bazel run //labs/raycaster:raycaster
```
