# Лабораторная работа №2: Raycaster

Проект реализует 2D-рейкастер на Qt Widgets:

- режим `light` для управления источником света;
- режим `polygons` для рисования многоугольников-препятствий;
- построение освещенной области рейкастингом;
- тени от препятствий;
- несколько близких источников света и полутени.

## Запуск

Из корня репозитория:

```bash
bazel run //labs/raycaster
```

## Управление

Верхний `QComboBox` переключает режимы:

- `light`:
  - источник света следует за курсором мыши;
- `polygons`:
  - `ЛКМ` — начать новый многоугольник или добавить вершину;
  - движение мыши — обновить последнюю preview-вершину;
  - `ПКМ` — завершить текущий многоугольник.

Важно: незавершенный многоугольник не создает тень, пока не завершен `ПКМ`.

## Что реализовано по условию

- классы `Ray`, `Polygon`, `Controller`;
- хранение данных сцены в `Controller`;
- фиктивный граничный многоугольник по краям области рисования;
- построение трех лучей в каждую вершину: основной и повернутые на `±0.0001`;
- поиск ближайшего пересечения луча с препятствиями;
- удаление почти совпадающих лучей;
- сортировка лучей по углу и сборка освещенной области;
- отрисовка света, теней и полутеней.

## Структура файлов

- `main.cpp` — запуск Qt-приложения;
- `main_window.*` — главное окно и верхний UI;
- `canvas_widget.*` — обработка мыши и отрисовка сцены;
- `ray.*` — луч и его поворот;
- `polygon.*` — вершины многоугольника и пересечение луча с ребрами;
- `controller.*` — хранение сцены и алгоритм рейкастинга.
