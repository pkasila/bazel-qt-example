MedicineApp - ReadMe
Приложение позволяет составлять план приёма лекарств, когда необходима сложная комплексная терапия.
Виджеты в приложении:
QCalendarWidget - позволяет составлять график приёма для каждого дня, при
добавлении лекарств в таблицу для определённого дня этот день получает специальное выделение
QTableWidget - непосредственно отображает название лекарства, дозировку,
время приёма и заметки, лекарства сортируются по времени приёма
QDialog - организует диалог по добавлению лекарств
QPushButton, QLineEdit, QTextEdit, QTimeBox, QComboBox - входят в диалоговое окно
Также при нажатии ПКМ на название лекарства организовано контекстное меню по удалению
и редактированию информации о лекарстве.
