# Задание 2 — Свободное плавание

## Идея приложения

Я сделал приложение **«Кошачья гавань: свободное плавание»**.

Это небольшое интерактивное Qt-приложение в морско-котячей теме. Пользователь управляет рейсом кота-капитана: задаёт имя, выбирает погоду, настраивает высоту волн, выбирает дату отплытия и строит маршрут. После этого можно проходить этапы маршрута, следить за риском рейса, смотреть детали каждой точки, фильтровать маршрут и экспортировать его в файл.

Приложение сделано не как случайный набор виджетов, а как единая идея: **котокорабль идёт по маршруту, а пользователь должен подстроить условия плавания так, чтобы этапы действительно можно было пройти**.

## Выбранные виджеты

### 4 basic widget

1. **QLineEdit**  
   Используется для ввода имени капитана-кота.  
   Реакция: при изменении текста обновляется заголовок окна и сводка рейса.

2. **QComboBox**  
   Используется для выбора погоды.  
   Реакция:
   - меняется бейдж погоды;
   - меняется описание настроения маршрута;
   - меняется риск рейса;
   - может заблокироваться следующий этап маршрута.

3. **QSlider**  
   Используется для задания высоты волн.  
   Реакция:
   - обновляется числовое значение волн;
   - пересчитывается риск рейса;
   - меняется доступность следующего этапа.

4. **QPushButton**  
   Используется для действий:
   - построить маршрут;
   - сбросить посещения;
   - экспортировать рейс в файл.  
   Реакция: по нажатию выполняется соответствующее действие.

### 2 других виджета

5. **QCalendarWidget**  
   Используется для выбора даты отплытия.  
   Реакция:
   - выбранная дата отображается в сводке;
   - дата влияет на риск рейса;
   - выходные добавляют штраф к риску;
   - дата сохраняется и попадает в экспорт.

6. **QListWidget**  
   Используется для отображения точек маршрута.  
   Реакция:
   - при выборе точки показываются её подробности;
   - при двойном клике происходит попытка пройти этап;
   - элементы визуально меняются в зависимости от состояния.

## Логика приложения

В приложении реализована не просто смена статусов, а логика прохождения маршрута.

### Как устроен маршрут

Маршрут состоит из нескольких этапов. Каждый этап имеет:
- название;
- задачу экипажа;
- подсказку;
- ограничение по максимально допустимому риску;
- иногда запрет на прохождение во время шторма.

### Правила прохождения

- Маршрут нужно проходить **строго по порядку**.
- Нельзя перепрыгивать через этапы.
- Только **следующий непройденный этап** может быть активным.
- Если условия рейса не подходят, этап становится **временно заблокированным**.
- Чтобы открыть заблокированный этап, пользователь должен изменить параметры рейса:
  - погоду;
  - высоту волн;
  - дату.

### Состояния этапов

У этапов есть 4 состояния:

- `🐟` — этап ещё впереди;
- `⭐` — текущий доступный этап;
- `🚧` — текущий этап временно заблокирован;
- `🐾` — этап уже пройден.

## Как пользоваться приложением

1. Введите имя капитана-кота.
2. Выберите погоду.
3. Настройте высоту волн с помощью слайдера.
4. Выберите дату отплытия в календаре.
5. Нажмите **«Построить маршрут 🧭»**.
6. Справа появится список этапов маршрута.
7. Нажмите на этап, чтобы посмотреть подробности.
8. Двойной клик по этапу пытается пройти его.
9. Если этап заблокирован, приложение объяснит причину.
10. Чтобы открыть заблокированный этап, измените параметры рейса.
11. Можно использовать поиск и фильтр по непосещённым этапам.
12. Кнопка **«Экспорт рейса в файл»** сохраняет подробный отчёт в `.txt`.

## Как работает календарь

Календарь в приложении нужен не только для красоты.

Он влияет на рейс так:
- выбранная дата отображается в сводке;
- дата попадает в описание этапов;
- дата сохраняется между запусками;
- дата попадает в экспорт;
- **если выбраны выходные, к риску рейса добавляется +5**.

Под календарём есть отдельная подпись, которая показывает, влияет ли текущая дата на риск.

## Горячие клавиши

В приложении реализованы горячие клавиши через `QShortcut`:

- **Ctrl+G** — построить новый маршрут
- **Ctrl+R** — сбросить посещения этапов
- **Ctrl+E** — экспортировать рейс в файл

## Дополнительные возможности

В приложение были добавлены дополнительные улучшения сверх базового задания.

### 1. Сохранение состояния между запусками

Сохраняются:
- имя капитана;
- выбранная погода;
- высота волн;
- дата;
- строка поиска;
- фильтр по непосещённым этапам;
- маршрут;
- статусы этапов;
- ограничения этапов;
- размер и положение окна.

После повторного запуска состояние восстанавливается автоматически.

### 2. Игровая логика прохождения маршрута

Приложение не позволяет просто “натыкать” статусы вручную:
- этапы идут по порядку;
- следующий этап может быть заблокирован;
- пользователь должен реально менять условия плавания.

Это делает приложение осмысленнее и креативнее.

### 3. Условия доступа к этапам

У каждого этапа есть собственные ограничения:
- максимальный безопасный риск;
- иногда запрет на прохождение во время шторма.

### 4. Индикатор сложности рейса

Добавлен отдельный расчёт риска.

Риск зависит от:
- погоды;
- высоты волн;
- даты;
- длины маршрута.

Он показывается:
- числом;
- текстовым уровнем сложности;
- цветным progress bar.

### 5. Фильтрация маршрута

Есть два инструмента фильтрации:
- поиск по названию этапа, задаче и подсказке;
- чекбокс **«Показывать только непосещённые точки»**.

### 6. Экспорт маршрута в файл

Рейс можно сохранить в `.txt`.

В экспорт попадают:
- имя капитана;
- дата;
- погода;
- волны;
- уровень риска;
- все этапы маршрута;
- состояния этапов;
- полные описания.

### 7. Улучшенное поведение при изменении размера окна

Чтобы интерфейс не ломался при уменьшении окна, сделано следующее:
- левая часть помещена в `QScrollArea`;
- правая часть разделена `QSplitter`;
- блок с деталями этапа сделан прокручиваемым;
- размеры виджетов ужаты так, чтобы всё лучше помещалось на экран.

### 8. Понятный календарь

Календарь специально оформлен без лишней визуальной путаницы:
- убрано странное красное поведение дат;
- отдельно подсвечен сегодняшний день;
- есть пояснение, как именно календарь влияет на риск.

### 9. Живые описания этапов

Если после построения маршрута изменить:
- погоду;
- волны;
- дату,

то логика маршрута и описания этапов пересчитываются автоматически.

### 10. Креативное оформление

В интерфейс добавлены:
- котики;
- морская тема;
- дружелюбные подписи;
- декоративные эмодзи-маркеры;
- визуально приятные карточки и панели.

## Какие сигналы, события и реакции можно проверить

Проверяющий может легко проверить работу сигналов и виджетов:

- **QLineEdit**  
  Изменить имя капитана → обновится заголовок и сводка.

- **QComboBox**  
  Изменить погоду → поменяются бейдж, настроение, риск и доступность этапов.

- **QSlider**  
  Изменить высоту волн → изменится число волн и риск рейса.

- **QPushButton**  
  Нажать кнопки:
  - построить маршрут;
  - сбросить посещения;
  - экспортировать рейс.

- **QCalendarWidget**  
  Выбрать другую дату → изменится пояснение под календарём и риск рейса.

- **QListWidget**  
  - клик по этапу → открываются подробности;
  - двойной клик по этапу → попытка пройти этап.

- **QShortcut**  
  Проверить:
  - `Ctrl+G`
  - `Ctrl+R`
  - `Ctrl+E`
