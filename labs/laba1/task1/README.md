## Дополнительные возможности

В приложение были добавлены дополнительные улучшения поверх базового задания:

- **Сохранение состояния между запусками**  
  Приложение сохраняет:
  - количество билетов;
  - названия билетов;
  - статусы билетов;
  - текущий выбранный билет;
  - размер и положение окна.  
  После повторного запуска всё восстанавливается автоматически.

- **Улучшенный дизайн интерфейса**  
  Добавлено аккуратное современное оформление:
  - мягкая pastel-цветовая палитра;
  - скруглённые карточки и кнопки;
  - цветные progress bar;
  - визуально выделенные секции интерфейса.

- **Кастомное цветовое выделение билетов**  
  Каждый билет в общем списке сразу визуально показывает свой статус:
  - светлый цвет для новых билетов;
  - жёлтый для билетов, которые стоит повторить ещё раз;
  - зелёный для полностью повторённых билетов.

- **Улучшенное выделение текущего билета**  
  Выбранный билет в списке дополнительно выделяется:
  - заметной рамкой;
  - более явным визуальным акцентом;
  - жирным шрифтом.  
  Это делает навигацию по билетам удобнее.

- **Иконки статусов в списке билетов**  
  У каждого билета рядом с названием отображается маркер статуса:
  - ⬜ — не повторял;
  - 🟨 — нужно ещё раз;
  - 🟩 — повторён.

- **История переходов по билетам**  
  Помимо случайного выбора следующего билета реализована история просмотров, благодаря которой можно вернуться к предыдущему открытому билету.

- **Декоративное оформление интерфейса**  
  В дизайн добавлены элементы с котиками и лапками, чтобы приложение выглядело более дружелюбно и запоминалось визуально.

- **Легенда статусов**  
  Над списком билетов добавлена наглядная легенда с цветами и обозначениями статусов, чтобы пользователь сразу понимал смысл каждой цветовой категории.

- **Адаптивное поведение интерфейса при изменении размера окна**  
  Интерфейс аккуратно растягивается и сохраняет читаемость благодаря использованию layout-ов и `QSplitter`.

- **Защита от неудачного взаимодействия**  
  В приложении предусмотрены удобные сценарии работы:
  - пустое имя билета не применяется;
  - кнопка перехода назад отключается, если история пуста;
  - при полном завершении повторения выводится отдельное уведомление.

## Запуск приложения

Файлы проекта находятся в папке:

`labs/laba1/task1`

После разбиения проекта структура такая:

- `main.cpp` — только точка входа (`QApplication` + запуск окна);
- `main_window.h` — интерфейс окна;
- `main_window.cpp` — каркас класса `MainWindow`;
- `main_window_ui.inl` — построение интерфейса и оформление;
- `main_window_logic.inl` — логика работы с билетами и прогрессом;
- `main_window_settings.inl` — сохранение/загрузка состояния.

Сборка из корня репозитория:

```bash
bazel build //labs/laba1/task1:laba1
```

Запуск из корня репозитория:

```bash
bazel run //labs/laba1/task1:laba1
```
