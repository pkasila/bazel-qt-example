# Лабораторная работа №2: 2D Рейкастер (2D Raycaster)

### Описание проекта
Данный проект представляет собой симуляцию 2D-освещения на плоскости. Система рассчитывает распространение света от источника, учитывая препятствия в виде произвольных многоугольников, и отрисовывает реалистичные тени и полутени.

### Реализованный функционал
1.  **Геометрическое ядро (Low-level Geometry):**
    *   Вся математика (пересечение отрезков, поворот векторов) реализована вручную без использования встроенных средств Qt (`QPolygon`, `QLineF` и др.).
    *   Класс `Ray` для управления лучами и их трансформации.
    *   Класс `Polygon` для хранения вершин и поиска точек пересечения с лучами.
2.  **Алгоритм Рейкастинга:**
    *   Для каждой вершины каждого многоугольника выпускается 3 луча (точно в вершину и с небольшим отклонением $\pm 0.0001$ рад) для корректной обработки углов.
    *   Сортировка лучей по углу для построения корректного многоугольника области видимости.
3.  **Система теней и полутеней:**
    *   Реализован эффект мягких теней (пенумбра) путем создания массива из 5 микро-источников света и наложения их полупрозрачных областей освещения друг на друга.
4.  **Режимы работы:**
    *   `<polygons>`: создание и редактирование геометрии сцены.
    *   `<light>`: управление положением источника света с помощью курсора.

### Управление
*   **Клавиша [P]**: Переход в режим редактирования многоугольников.
    *   **ЛКМ**: Поставить новую вершину.
    *   **ПКМ**: Завершить текущий многоугольник.
*   **Клавиша [L]**: Переход в режим управления светом.
    *   **Движение мыши**: Перемещение источника света по экрану.
*   **Автоматические границы**: По краям области рисования добавлен невидимый многоугольник-рамка, в который упираются лучи.

### Технический стек
*   **C++ 17**
*   **Qt 6** (только для визуализации и обработки событий)
*   **Bazel** (система сборки)

### Сборка и запуск
Для запуска проекта используйте стандартную команду Bazel:

```bash
bazel run //labs/raycaster:basics
```
