# Task 1: Ticket Repetition App

Приложение для повторения экзаменационных билетов.

## Сборка

```bash
bazel build //labs/basics/task1:task1
```

## Запуск

```bash
bazel run //labs/basics/task1:task1
```

## Реализованные возможности

- `count` (`QSpinBox`): изменение количества билетов с полным сбросом списка к дефолтным именам и серому статусу.
- `view` (`QListWidget`): отображение всех билетов, цветовой статус, выбор по клику, смена статуса по двойному клику.
- `question-view`: номер, имя, редактирование имени через `QLineEdit` по `Enter`, выбор статуса через `QComboBox`.
- `next-question`: случайный выбор только среди билетов со статусами `default`/`yellow`.
- `previous-question`: возврат к предыдущему выбранному билету.
- `total-progress`: прогресс по билетам не в `default`.
- `пройденный прогресс`: прогресс по билетам в статусе `green`.
- Используются layout-ы и адаптивное масштабирование интерфейса при изменении размера окна.
