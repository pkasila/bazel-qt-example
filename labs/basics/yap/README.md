## Yet Another Paint

Простая рисовалка (MVP).

### Фичи
- Несколько тулов: перемещение, перо, прямоугольник.
- Включение/выключение внутреннего заполнения фигур.
- Изменение размера пера.
- Очистка экрана.
- Масштабирование колесом мыши.
- Перемещение по полю на ПКМ и, если зажаты клавиши ctrl или shift, на ЛКМ.
- Масштабная сетка на заднем фоне.
- Иконки поддерживают светлые и темные темы.

### Используемые виджеты
- `QToolBar` - Общий виджет тулбара.
- `QAction` - Кнопки тулов.
- `QActionGroup` - Автоматическое сохранение инвариантна единственности выбранного тула.
- `QWidget` - Разделитель для элементов в тулбаре.
- `QLabel` - Отображение дополнительных иконок в тулбаре.
- `QSlider` - Настройка размера пера.
- `QGraphicsView` - Контейнер для удобной работы с `QGraphicsScene`.
- `QGraphicsScene` - Виджет для отрисовки графических объектов.
