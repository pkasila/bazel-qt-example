# Factorizer - Разложение числа на простые множители

## Творческая задумка

Factorizer - это не просто утилита для разложения чисел на простые множители, а **образовательно-развлекательное приложение**, которое превращает скучную математическую операцию в увлекательный процесс с визуальной анимацией и элементами геймификации.

### Ключевые творческие решения:

1. **Анимация факторизации**
   - Процесс разложения отображается поэтапно, как на уроке математики
   - Каждый множитель появляется последовательно, создавая эффект "живого" решения
   - Пользователь может контролировать скорость анимации

2. **Двойной алгоритм**
   - Классический метод перебора (для понимания алгоритма)
   - Оптимизированный алгоритм с решетом Эратосфена (для скорости)
   - Пользователь может сравнивать эффективность подходов

3. **Интерактивная история**
   - Сохраняется история всех разложений
   - Клик по истории мгновенно повторяет факторизацию
   - Визуальное представление результата в удобном формате

4. **Обратная связь в реальном времени**
   - Статус-бар с информацией о текущем действии
   - Прогресс-бар, отражающий ход факторизации
   - Подсказки и предупреждения при вводе

## Виджеты и их функциональность

### Основные виджеты (Basic Widgets):

#### 1. **QLineEdit** (Поле ввода числа)
- **Сигнал**: `textChanged` - реагирует на каждое изменение текста
- **Событие**: `returnPressed` (Enter) - запускает факторизацию
- **Функция**: Валидация ввода, автоматическое включение/отключение кнопки

#### 2. **QPushButton** (Кнопка "Factorize")
- **Сигнал**: `clicked` - запускает процесс факторизации
- **Состояние**: Включается только при корректном вводе (число ≥ 2)
- **Визуальный эффект**: Изменение цвета при наведении и нажатии

#### 3. **QPushButton** (Кнопка "Clear")
- **Сигнал**: `clicked` - очищает все поля
- **Дополнительно**: Останавливает анимацию, сбрасывает прогресс

#### 4. **QTextEdit** (Область вывода результата)
- **Свойства**: Только для чтения, моноширинный шрифт
- **Функция**: Отображение результата с анимацией появления множителей
- **Авто-скроллинг**: Прокручивается к новым данным

### Дополнительные виджеты (Creative Widgets):

#### 5. **QCheckBox** (Переключатель алгоритма)
- **Сигнал**: `toggled` - переключение между алгоритмами
- **Образовательная ценность**: Позволяет сравнить скорость работы алгоритмов
- **Обратная связь**: Изменяет статус-бар с информацией о выбранном алгоритме

#### 6. **QSlider** (Регулятор скорости анимации)
- **Сигнал**: `valueChanged` - изменение скорости анимации
- **Диапазон**: 0-1000 мс (0 = мгновенное отображение)
- **Визуализация**: Отображение текущего значения в миллисекундах

#### 7. **QProgressBar** (Индикатор прогресса)
- **Обновление**: В реальном времени при анимации
- **Функция**: Визуализация завершенности процесса факторизации
- **Цветовая индикация**: Зеленый цвет при завершении

#### 8. **QListWidget** (История факторизаций)
- **Сигнал**: `itemClicked` - повторная факторизация числа
- **Хранение**: До 20 последних результатов
- **Формат**: Отображение в виде "84 = 2 × 2 × 3 × 7"

## Сигналы и их обработка

| Виджет | Сигнал | Обработчик | Действие |
|--------|--------|------------|----------|
| QLineEdit | textChanged | onNumberChanged | Валидация, управление кнопкой |
| QLineEdit | returnPressed | onEnterPressed | Запуск факторизации |
| QPushButton | clicked | onFactorizeClicked | Основная логика разложения |
| QPushButton | clicked | onClearClicked | Очистка всех полей |
| QCheckBox | toggled | onUseSieveToggled | Смена алгоритма |
| QSlider | valueChanged | onDelayChanged | Изменение скорости анимации |
| QListWidget | itemClicked | onHistoryItemClicked | Повтор предыдущего расчета |
| QTimer | timeout | onAnimationTimer | Пошаговая анимация |

## Как пользоваться

### Базовое использование:
1. **Введите число** в поле ввода (например, 84)
2. **Нажмите Enter** или кнопку "Factorize"
3. **Наблюдайте** за анимацией появления множителей
4. **Просматривайте** результат в формате "84 = 2 × 2 × 3 × 7"

### Продвинутые возможности:

#### Настройка анимации
- Перемещайте **слайдер** для изменения скорости (0-1000 мс)
- При значении 0 анимация отключается (мгновенный результат)
- При больших значениях можно наблюдать пошаговое разложение

#### Выбор алгоритма
- **Включите "Use Sieve"** для быстрой факторизации больших чисел
- **Выключите** для демонстрации классического алгоритма
- Сравните скорость работы на больших числах (например, 999983)

#### Использование истории
- Все разложенные числа сохраняются в истории
- **Кликните** на любой элемент истории для повторной факторизации
- История хранит последние 20 операций

#### ⌨Горячие клавиши
- **Enter** в поле ввода - запуск факторизации
- **Tab** - навигация между элементами
- **Alt+F4** - закрытие приложения

### Примеры для тестирования:

| Число | Результат |
|-------|-----------|
| 2 | 2 is prime |
| 84 | 84 = 2 × 2 × 3 × 7 |
| 997 | 997 is prime (простое число) |
| 123456 | 123456 = 2 × 2 × 2 × 2 × 2 × 2 × 3 × 643 |
| 999983 | 999983 is prime (большое простое) |

## Архитектура

### Классы и структуры:
- **PrimeFactorizer**: Главный класс приложения
- **История**: `std::vector<std::pair<long long, std::vector<long long>>>`
- **Таймер анимации**: `QTimer` для пошагового отображения

### Алгоритмы:
1. **Trial Division**: Классический метод перебора делителей
2. **Sieve-based**: Оптимизированный с использованием решета Эратосфена

### Особенности реализации:
- Асинхронная обработка для сохранения отзывчивости UI
- Пошаговая анимация с возможностью прерывания
- Автоматическая валидация ввода (только числа, не меньшие 2)
