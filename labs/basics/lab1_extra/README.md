# Smart Lighting Control System

## Описание

Интерактивное приложение для управления освещением в разных комнатах дома. Позволяет регулировать яркость, температуру цвета и отслеживать статус в реальном времени.

## Ключевые особенности

### Основные виджеты (4 шт):
1. **QSlider** - управление яркостью (0-100%). Отправляет сигнал `valueChanged()` при изменении
2. **QDial** - выбор температуры цвета (3000-8000K). Отправляет сигнал `valueChanged()` при вращении
3. **QCheckBox** - включение/выключение света. Отправляет сигнал `toggled()` при нажатии
4. **QComboBox** - выбор комнаты (Living Room, Bedroom, Kitchen, Bathroom, Office). Отправляет сигнал `currentTextChanged()` при смене

### Дополнительные виджеты (2 шт):
5. **QLCDNumber** - цифровое отображение текущей яркости. Реагирует на `brightnessChanged` сигнал
6. **QPushButton** - кнопки для сохранения и применения preset'ов. Отправляют сигналы `clicked()` при нажатии

### Вспомогательные компоненты:
- **QProgressBar** - визуальное отображение уровня яркости
- **QLabel** - отображение информации и статуса
- **QFrame** - цветовой preview, реагирующий на изменения температуры и яркости
- **QGroupBox** - организация UI в логические группы

## Сигналы и слоты

### Сигналы:
- `QSlider::valueChanged()` → `OnBrightnessChanged()` - обновляет яркость
- `QDial::valueChanged()` → `OnColorTemperatureChanged()` - меняет цвет
- `QCheckBox::toggled()` → `OnPowerToggled()` - включает/выключает свет
- `QComboBox::currentTextChanged()` → `OnRoomChanged()` - переключает комнату
- `QPushButton::clicked()` → `OnPresetClicked()`,  `OnSavePresetClicked()` - применяет preset или сохраняет

### События:
- Изменение размера окна - все элементы масштабируются благодаря QHBoxLayout/QVBoxLayout

## Взаимодействие с приложением

1. **Выбор комнаты** - используйте dropdown меню слева для выбора комнаты
2. **Включение/выключение** - нажмите checkbox "Power" для включения/выключения света
3. **Регулировка яркости** - используйте горизонтальный слайдер, яркость отобразится в %
4. **Выбор температуры цвета** - вращайте диал для выбора (3000K теплый, 8000K холодный)
5. **Быстрые preset'ы** - нажмите одну из кнопок "Warm", "Neutral" или "Cool"
6. **Сохранение параметров** - нажмите кнопку "💾 Save Current Settings" для сохранения текущих параметров комнаты

## Интерфейс

### Левая панель:
- Выбор комнаты
- Quick presets для температуры цвета
- Кнопка сохранения
- Статус-bar

### Средняя панель:
- Checkbox включения/выключения
- Слайдер и прогресс-бар яркости
- Диал для выбора температуры цвета в Кельвинах

### Правая панель:
- Живой preview цвета (меняется в реальном времени)
- LCD дисплей для отображения яркости
- Информационная панель с текущими параметрами

## Технические детали

- **Язык**: C++17 с Qt5
- **Архитектура**: MVC-подобная с классом `LightingController`
- **Управление состоянием**: `LightState` структура для хранения параметров каждой комнаты
- **Цветовое преобразование**: Алгоритм преобразования цветовой температуры (Kelvin) в RGB
