# 2D Raycasting Lighting System

Гэта інтэрактыўная сістэма мадэлявання 2D-асвятлення і ценяў у рэальным часе, распрацаваная на C++ з выкарыстаннем фрэймворка Qt.

## 🌟 Асаблівасці
* **Дынамічныя цені**: Разлік вобласці бачнасці (Field of View) у рэальным часе.
* **Рэдактар геаметрыі**: Магчымасць ствараць і рэдагаваць шматкутнікі (сцены), якія блакуюць святло.

## 🛠 Тэхналогіі
* **C++17**
* **Qt 6** (Core, Gui, Widgets)
* **Bazel** (Build system)

## ⌨️ Кіраванне

| Рэжым | Дзеянне | Вынік |
| :--- | :--- | :--- |
| **Святло** | ЛКМ (заціснуць) | Перамяшчэнне ліхтара |
| **Святло** | ПКМ на ліхтары | Змяніць колер / Выдаліць |
| **Святло** | ПКМ на фоне | Дадаць новы ліхтар |
| **Сцены** | ЛКМ | Паставіць кропку (вяршыню) |
| **Сцены** | ПКМ | Замкнуць шматкутнік |
