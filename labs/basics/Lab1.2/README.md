Добро пожаловать в мой проект — уютный дневник настроения💋! Это приложение создано для того, чтобы помочь пользователю фиксировать свои мысли, отслеживать эмоциональное состояние и просто радоваться милому дизайну.

✨ В этом приложении ты можешь указать уровень своего настроения (что отразится в шкале магии✨),и помни, в случае плохого настроения приложение всегда тебя поддержит 🤗 и даже предложит словить звёздочку🤭! Здесь ты можешь поделиться своим секретиком👠 и включить режим блёсток 🧚🏻‍♀️




Согласно заданию, в приложении реализованы следующие компоненты:

1. Виджеты (6 штук)

- **QPushButton** (Кнопка "Поймать звезду") — увеличивает счетчик звезд
- **QLineEdit** (Поле ввода) — позволяет записывать мысли
- **QSlider** (Ползунок настроения) — отражает уровень счастья
- **QCheckBox** (Чекбокс блесток) — динамически меняет стиль приложения

- **QCalendarWidget** — интерактивный календарь для выбора даты
- **QProgressBar** — визуализирует данные со слайдера (шкала "магии")

2. Взаимодействие (Сигналы и События)

- **Signal:** `clicked` у кнопки → увеличивает счетчик и обновляет текст
- **Signal:** `valueChanged` у слайдера → синхронно меняет значение QProgressBar и обновляет статусное сообщение
- **Signal:** `returnPressed` у строки ввода (клавиша Enter) → "сохраняет" мысль и очищает поле
- **Signal:** `stateChanged` у чекбокса → включает "режим блесток" 
- **Signal:** `selectionChanged` в календаре → выводит выбранную дату 
- **Event:** Переопределен метод `keyPressEvent`. Если нажать на клавиатуре клавишу 'S', сработает функция поимки звезды

4. Дизайн


- Нежно-розовый фон 🩷
- Скругленные углы у кнопок и полей ввода 🎀
- Режим блесток 🌷

   Как пользоваться

1. Выбери дату в календаре🦩 
2. Двигай слайдер, чтобы установить свое настроение. Следи, как меняется шкала магии! 🌸
3. Напиши секрет в текстовое поле и нажми Enter 💘
4. Нажимай на кнопку "Поймать звезду" или просто жми клавишу 'S' на клавиатуре💞 
5. Поставь галочку "Добавить блесток", чтобы преобразить интерфейс💖
