# Лабораторная работа 2 — «Свободное плавание»

## Идея

Приложение сделано в виде небольшого пульта управления батискафом.
Пользователь задаёт имя аппарата, выбирает глубину, включает тихий режим и запускает погружение.
Во время миссии расходуется кислород, интерфейс меняет состояние и цветовую тему, а статусная строка постоянно сообщает, что происходит.

Идея выбрана специально так, чтобы приложение было легко проверять:
- все виджеты видны сразу;
- каждый виджет участвует в сигнале, событии или реакции на сигнал;
- изменение размера окна видно напрямую, потому что меняются размеры контролов и шрифтов.

## Использованные виджеты

### 4 basic widget
1. `QLabel` — статусный экран сверху
2. `QLineEdit` — ввод имени батискафа
3. `QPushButton` — запуск и пауза миссии
4. `QCheckBox` — включение тихого режима

### 2 других виджета
5. `QSlider` — выбор глубины погружения
6. `QProgressBar` — запас кислорода

## Что у кого проверять

### `QLineEdit`
- посылает сигнал `textChanged`
- приложение обновляет статус и имя батискафа

### `QPushButton`
- посылает сигнал `clicked`
- запускает или ставит на паузу миссию

### `QCheckBox`
- посылает сигнал `toggled`
- включает тихий режим и меняет оформление интерфейса

### `QSlider`
- посылает сигнал `valueChanged`
- меняет глубину, обновляет подсказку и статус

### `QProgressBar`
- реагирует на пользовательский сигнал `oxygenLevelChanged`
- показывает текущий процент кислорода

### `QLabel`
- реагирует на пользовательский сигнал `statusTextChanged`
- показывает состояние батискафа и подсказки игроку

## Дополнительно обрабатываемые события

### Изменение размера окна
Обработан `resizeEvent`.
При изменении размера окна:
- пересчитываются размеры контролов;
- пересчитываются размеры шрифтов;
- в заголовке окна показывается текущий размер.

### Горячие клавиши
Они не обязательны для запуска приложения, но добавлены для удобства и креативности.

- `S` — запустить или поставить на паузу миссию
- `R` — мгновенно восстановить кислород
- `Space` — быстро увеличить глубину

Если проверяющий хочет проверить только мышкой, этого тоже достаточно:
- ввести имя;
- подвигать слайдер;
- включить и выключить чекбокс;
- нажать кнопку запуска.

## Как взаимодействовать с приложением

1. Введите название батискафа в поле ввода.
2. Передвиньте слайдер на нужную глубину.
3. При желании включите тихий режим.
4. Нажмите кнопку запуска.
5. Следите за уменьшением кислорода.
6. Нажмите `R`, если хотите восстановить кислород.
7. Нажмите `Space`, если хотите быстро углубиться.

## Почему работа подходит под условия задания

- Есть 6 виджетов, из них 4 basic и 2 other.
- Каждый виджет либо посылает сигнал, либо реагирует на сигнал.
- Присутствует обработка события изменения размера окна.
- Используются layout'ы, поэтому окно растягивается корректно.
- Визуальная тема меняется в зависимости от глубины, режима и запаса кислорода.
- Есть простая игровая идея, а не просто набор разрозненных кнопок.

## Сборка

В проекте есть `BUILD` файл под `rules_qt`.
Предполагается, что `rules_qt` уже подключён в вашем Bazel-проекте.

Сборка:

```bash
bazel build //:free_swim_lab
```

Запуск:

```bash
bazel run //:free_swim_lab
```
