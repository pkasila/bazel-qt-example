# English Language Tutor (Qt/C++)

Десктопное приложение для изучения английского языка с упражнениями на перевод и грамматику.

**Ключевые особенности:**
*   **Упражнения:** Перевод предложений и грамматические тесты (выбор варианта).
*   **Уровни:** Elementary, Intermediate, Advanced.
*   **База данных:** Вопросы хранятся в SQLite, импортируются из `.txt` файлов при первом запуске.
*   **Динамика:** `QStackedWidget` для смены упражнений в одном окне.
*   **Оценка:** Баллы за сессии без ошибок, лимит попыток, таймер.
*   **Интерфейс:** стилизация через QSS.
*   **Подсказки:** Клавиша "H" для помощи по текущему заданию.

**Сборка (Bazel):**
Используйте `bazel run labs/basics/Duolingo:duolingo`
