# Ticket Review Application

Приложение для эффективного повторения экзаменационных билетов с системой отслеживания прогресса и случайным выбором вопросов.

## Обзор

Ticket Review Application - это десктопное приложение на Qt/C++, разработанное для помощи в подготовке к экзаменам. Оно позволяет управлять списком билетов, отслеживать прогресс их изучения и предоставляет удобный интерфейс для повторения материала.

## Основные возможности

### Управление билетами
- **Настройка количества билетов**: SpinBox для задания общего числа билетов (от 0 до 1000)
- **Именование билетов**: Возможность задать пользовательские названия для каждого билета
- **Визуальное отображение**: Список всех билетов с цветовой индикацией статуса

### Система статусов
Каждый билет может находиться в одном из трех состояний:

| Статус | Цвет | Описание |
|--------|------|----------|
| Не повторяли | Серый (#E0E0E0) | Билет еще не просматривался |
| Требует повторения | Желтый (#FFF59D) | Билет просмотрен, но нужно повторить еще раз |
| Выучен | Зеленый (#A5D6A5) | Билет полностью освоен |

### Навигация и управление
- **Клик по билету**: Отображает детальную информацию о билете
- **Двойной клик**: 
  - На сером/желтом билете → становится зеленым
  - На зеленом билете → становится желтым
- **Кнопка "Next**: Случайный выбор следующего билета из неповторенных
- **Кнопка "Previous"**: Возврат к предыдущему просмотренному билету

### Редактирование информации
- **Название билета**: 
  - Отображается в списке и в информационной панели
  - Редактируется через QLineEdit
  - Сохраняется по нажатию Enter (при непустом поле)
- **Статус**: Изменяется через выпадающий список QComboBox

### Отслеживание прогресса
Два индикатора прогресса:

1. **Total Progress (Общий прогресс)**:
   - Серый билет: 0%
   - Желтый билет: 50%
   - Зеленый билет: 100%
   - Отображает средневзвешенный прогресс

2. **Green Progress (Выученные билеты)**:
   - Процент билетов со статусом "Выучен"

### Основные компоненты

#### Класс TicketReviewApp
Главный класс приложения, наследующийся от QMainWindow. Управляет:
- Хранением данных о билетах (std::vector<TicketInfo>)
- Историей просмотров (std::stack<int>)
- Всеми элементами интерфейса
- Обработкой событий

#### Структура TicketInfo
```cpp
struct TicketInfo {
    QString name;    // Название билета
    int status;      // Статус: 0 - серый, 1 - желтый, 2 - зеленый
};
```

## Установка и запуск

### Требования
- Qt 5 или Qt 6
- C++17 совместимый компилятор
- Bazel (для сборки)

### Сборка с Bazel

1. Убедитесь, что Qt установлен и доступен в системе
2. Настройте WORKSPACE файл для Qt (см. пример в документации)
3. Выполните сборку:
```bash
bazel build //:TicketReviewApp
```

4. Запустите приложение:
```bash
bazel run //:TicketReviewApp
```

## Использование

### Базовый сценарий работы

1. **Настройка количества билетов**
   - Используйте счетчик в верхней части окна
   - По умолчанию установлено 10 билетов

2. **Просмотр билетов**
   - Кликните на любой билет в списке слева
   - Справа отобразится детальная информация

3. **Изменение названия**
   - Введите новое название в поле "Edit name"
   - Нажмите Enter для сохранения

4. **Изменение статуса**
   - Выберите статус из выпадающего списка
   - Цвет билета в списке изменится автоматически

5. **Навигация**
   - Нажмите "Next" для случайного выбора следующего билета
   - Нажмите "Previous" для возврата к предыдущему

6. **Быстрое изменение статуса**
   - Дважды кликните по билету в списке для переключения:
     - Серый/желтый → зеленый
     - зеленый → желтый

## Дизайн и UX

### Визуальные особенности
- **Адаптивный интерфейс**: Использование QHBoxLayout и QVBoxLayout для корректного отображения при любом размере окна
- **Цветовая кодировка**: Интуитивно понятная система цветов для быстрой оценки прогресса
- **Группировка элементов**: Логическое разделение на панель управления и панель информации
- **Обратная связь**: Информационные сообщения при завершении всех билетов

### Удобство использования
- **Минимальное количество кликов**: Основные действия выполняются в 1-2 клика
- **Подсказки**: Placeholder в поле редактирования имени
- **Сохранение истории**: Возможность вернуться к предыдущим билетам

## Технические детали

### Используемые технологии
- **Qt Framework**: Виджеты, сигналы/слоты, система событий
- **STL**: std::vector, std::stack, std::random_device, std::mt19937
- **QString**: Для работы со строками (совместимость с Qt)

### Особенности реализации

#### Система сигналов/слотов
```cpp
connect(nextQuestionButton, &QPushButton::clicked, 
        this, &TicketReviewApp::onNextQuestionClicked);
```
Все взаимодействия с пользователем реализованы через механизм сигналов и слотов Qt.

#### Случайный выбор
Используется STL-генератор случайных чисел:
```cpp
static std::random_device rd;
static std::mt19937 gen(rd());
std::uniform_int_distribution<> dis(0, unfinished.size() - 1);
```

#### История навигации
Стек хранит индексы просмотренных билетов:
- При нажатии "Next" текущий билет сохраняется
- При нажатии "Previous" извлекается последний сохраненный

## Известные ограничения

1. Максимальное количество билетов ограничено 1000 (можно изменить в коде)
2. При изменении количества билетов история навигации сбрасывается
3. Не сохраняется состояние между сеансами работы
