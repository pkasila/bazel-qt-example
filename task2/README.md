# Task 2: CS Study Focus Station (Улучшенная версия)

## Творческая задумка
**Focus Station** — это интерактивная панель управления для студента, помогающая сосредоточиться на учебе. Приложение объединяет в себе таймер по методике Помодоро, систему заметок, трекер активности и настройки "атмосферы". Дизайн выполнен в современном темном стиле с возможностью переключения на "Cyber Neon".

## Использованные виджеты (Всего: 10)

### 1. Basic Widgets (6 шт.)
1.  `QLineEdit` — Поле для ввода названия текущей сессии (отправляет сигналы при изменении текста).
2.  `QDial` — Круговой регулятор для установки длительности сессии (сигнал `valueChanged`).
3.  `QSlider` — Горизонтальный слайдер для настройки громкости фоновой музыки (сигнал `valueChanged`).
4.  `QComboBox` — Выбор визуальной темы (сигнал `currentIndexChanged` переключает QSS стили всего приложения).
5.  `QTextEdit` — Область для ведения заметок во время сессии.
6.  `QCheckBox` — Переключатель режима "Без уведомлений".

### 2. Другие виджеты (4 шт.)
7.  `QCalendarWidget` — Календарь для просмотра истории учебных сессий (сигнал `clicked` выводит сводку за день).
8.  `QLCDNumber` — Ретро-дисплей для отображения обратного отсчета времени.
9.  `QProgressBar` — Визуализация прогресса текущей сессии.
10. `QTabWidget` — Организация интерфейса: разделение на рабочую зону ("Focus") и настройки ("Stats & Settings").

## Сигналы и Слоты (Взаимодействие)
1.  **Настройка таймера**: При вращении `QDial` обновляется значение на `QLCDNumber` и сбрасывается `QProgressBar`.
2.  **Запуск сессии**: Кнопка "Start" запускает `QTimer`. Каждую секунду срабатывает слот `onTimerTick`, который обновляет заголовок окна, текст на LCD и прогресс-бар.
3.  **Смена темы**: При выборе в `QComboBox` приложение на лету переключает таблицы стилей (QSS), меняя цвета, шрифты и границы виджетов.
4.  **Работа с историей**: Клик по дате в `QCalendarWidget` открывает диалоговое окно со сводкой успеваемости (имитация работы с данными).
5.  **Динамический UI**: Кнопка "Pause" меняет свой цвет и текст в зависимости от состояния таймера.

## Как запустить и использовать
1.  **Установка времени**: Вращайте диск (Dial) на вкладке "Focus", чтобы установить минуты.
2.  **Заметки**: Впишите тему занятия в поле ввода и делайте пометки в текстовом поле ниже.
3.  **Таймер**: Нажмите "Start Session". Заполнится прогресс-бар, а по окончании появится поздравление.
4.  **Настройки**: Перейдите на вкладку "Stats & Settings", чтобы сменить тему на **Cyber Neon** или посмотреть календарь.
