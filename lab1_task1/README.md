# Task1: Ticket Trainer (Qt + Bazel)

## Идея
Приложение помогает тренировать набор билетов: вы задаете количество, выбираете билет из списка или переходите к случайному следующему, меняете имя и статус, а прогресс пересчитывается автоматически.

Статусы билета:

- `Default` (0) — билет еще не прорабатывался
- `Need repeat` (1) — билет нужно повторить
- `Done` (2) — билет выучен

## Что есть в интерфейсе
- `Number of tickets` — количество билетов
- `ticketList` — список билетов вида `Ticket 1`, `Ticket 2`, ...
- `Question view` — данные выбранного билета
- `statusCombo` — смена статуса
- `Next random question` — переход к случайному доступному билету
- `Previous question` — возврат к предыдущему билету из истории
- `Total progress` — доля билетов со статусами `Need repeat` или `Done`
- `Fully learned` — доля билетов со статусом `Done`

## Как пользоваться
1. Выберите количество билетов в поле **`Number of tickets`**.
2. В левом списке появятся билеты `Ticket 1`, `Ticket 2`, и так далее.
3. Нажмите на билет в списке, чтобы открыть его в блоке **`Question view`**.
4. Чтобы переименовать билет, введите новое имя в поле **`Enter new ticket name and press Enter`** и нажмите **Enter**.
5. Чтобы сменить статус, выберите нужное значение в **`statusCombo`**.
6. Чтобы быстро переключить статус из списка, сделайте двойной клик по билету:
   - если статус был `Done`, он станет `Need repeat`
   - в остальных случаях он станет `Done`
7. Кнопка **`Next random question`** выбирает случайный билет со статусом `Default` или `Need repeat`.
8. Если подходящих билетов больше нет, приложение показывает окно `Done!`.
9. Кнопка **`Previous question`** возвращает к предыдущему билету из истории переходов.

## Клавиатура
- В поле переименования нажатие **Enter** применяет новое имя к выбранному билету.

## Запуск
Из корня репозитория:

```bash
bazel run //lab1_task1:app
```
