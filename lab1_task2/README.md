# Task2: Habit Tracker (Qt + Bazel)

## Идея
Небольшой трекер привычек с просмотром по датам: можно добавлять привычки, фильтровать их по категории, отмечать выполнение на выбранный день, смотреть историю и архивировать больше неактуальные привычки.

## Что есть в интерфейсе
- Кнопки `<`, `>`, `Today` — переход между датами
- `Jump to date` — быстрый выбор даты через календарь
- `Enter habit name` — ввод названия привычки
- `categoryBox` — категория новой привычки
- `Filter` — фильтр списка по категории
- `habitList` — список привычек, видимых на выбранную дату
- `Habit details` — информация о выбранной привычке
- `Done on selected day` — отметка выполнения на текущую выбранную дату
- `Toggle status` — быстрый переключатель состояния
- `Archive habit` — архивирование привычки
- `Progress for DD.MM.YYYY` — прогресс по видимым привычкам на выбранный день

## Как пользоваться
1. Выберите дату:
   - кнопками **`<`** и **`>`** можно перейти на предыдущий или следующий день
   - кнопка **`Today`** возвращает к текущей дате
   - через **`Jump to date`** можно сразу открыть нужный день
2. Добавьте привычку:
   - введите название в поле **`Enter habit name`**
   - выберите категорию: `Sport`, `Study`, `Sleep`, `Nutrition` или `Other`
   - нажмите **`Add habit`** или **Enter**
3. При добавлении привычка получает дату начала, равную текущей выбранной дате.
4. При необходимости отфильтруйте список через **`Filter`**.
5. Выберите привычку в **`habitList`**, чтобы открыть детали справа.
6. Для выбранной привычки можно:
   - поставить или снять флажок **`Done on selected day`**
   - нажать **`Toggle status`**, чтобы инвертировать состояние
   - нажать **`Archive habit`**, чтобы скрыть привычку из активного списка
7. Прогресс внизу окна пересчитывается автоматически для всех привычек, которые видны на выбранную дату с учетом текущего фильтра.

## Логика отображения
- Привычка видна только если она активна и ее `startDate` не позже выбранной даты.
- Архивированные привычки перестают отображаться как активные.
- История выполнения хранится отдельно для каждой даты.
- Заголовок даты показывает режим:
  - `Today` — если открыта текущая дата
  - `History` — если открыта любая другая дата

## Клавиатура
- В поле **`Enter habit name`** нажатие **Enter** добавляет новую привычку.
- В окне приложения:
  - **Left** — предыдущий день
  - **Right** — следующий день
  - **T** — перейти к сегодняшней дате
  - **Delete** — архивировать выбранную привычку

## Запуск
Из корня репозитория:

```bash
bazel run //lab1_task2:task2
```
